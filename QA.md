# Проверка

Программная проверка взаимодействий выполнена в DOM-окружении jsdom:

- На экране 30 столиков.
- Меню содержит 341 уникальную позицию, для каждой имеется локальный файл фотографии.
- Поиск работает без учёта регистра, показывает пустое состояние для неизвестного блюда.
- Категория «Пицца» показывает 14 позиций из исходного меню.
- Повторное добавление увеличивает количество; уменьшение до нуля удаляет позицию.
- Данные восстанавливаются при повторной инициализации страницы из сохранённого хранилища.
- Заказы столиков 1 и 2 разделены.
- Отмена очистки сохраняет заказ; подтверждение очищает только выбранный столик.
- Если заказ изменился после открытия подтверждения, требуется повторное подтверждение актуальной суммы.
- Карточка блюда открывает описание и позволяет добавить блюдо.
- Фильтры свободных столиков и столиков с заказами работают.
- Ошибка записи хранилища не приводит к применению несохранённого изменения.
- Повреждённые записи не удаляются; редактирование блокируется.
- Синтаксис JavaScript проверен Node.js.

Полная визуальная проверка в настоящем браузере не выполнена: браузерный движок недоступен в среде проверки. Адаптивные правила для телефона, планшета и компьютера реализованы, но требуют проверки на реальных устройствах. Тесты используют имитацию открытия dialog; Escape и нативный фокус управляются самим браузером и не проверены этим окружением.

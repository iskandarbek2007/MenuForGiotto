# Giotto — приём заказов

Сайт написан только на HTML, CSS и JavaScript, без фреймворков и сборки.

## Запуск

Откройте файл `index.html` в современном браузере. Для стабильной работы хранилища рекомендуется разместить содержимое папки сайта на обычном статическом хостинге. Для локального HTTP-сервера при наличии Python выполните из этой папки:

```sh
python -m http.server 8080 
```

После этого откройте http://localhost:8080 в браузере.

## Работа официанта

1. Выберите один из 30 столиков.
2. Найдите блюдо по названию или ингредиенту, при необходимости выберите категорию.
3. Нажмите «+» на карточке блюда. Нажатие на фотографию открывает описание.
4. Меняйте количество кнопками «−» и «+» в заказе. При уменьшении до нуля блюдо удаляется.
5. Вернитесь к столикам или закройте страницу: каждое изменение сразу сохраняется.
6. Когда клиент уйдёт, нажмите «Очистить столик» и подтвердите удаление. «Отмена» и Escape сохраняют заказ.

## Сохранение

Заказы хранятся в localStorage отдельно для каждого столика. Они доступны после перезагрузки и закрытия страницы в том же браузере и на том же адресе сайта. Вкладки одного браузера обновляют данные через событие storage. Если запись не удалась, изменение не применяется и показывается предупреждение. При повреждении записей редактирование блокируется без удаления исходных данных.

Смена домена, браузера, устройства или очистка данных сайта создаёт другое либо пустое хранилище. Приватный режим может удалять данные при закрытии браузера. Одновременное редактирование одного столика в разных вкладках не является полноценной многопользовательской системой: в редкой ситуации последняя запись может перезаписать другое изменение. Для нескольких официантов на разных устройствах требуется серверное хранилище.

## Меню

Источник: https://fergana.menu-giotto.uz/ — снимок от 4 октября 2026 года.
Импортировано 401 блюдо и напиток, 30 категорий и 401 фотография блюд; цены указаны в сумах, как в источнике. Родительская категория Giotto Бар объединяет подкатегории напитков. Это копия меню, цены не обновляются автоматически. Сервисный сбор не добавляется.

`menu.js` — данные меню; `` — фотографии; `app.js` — логика; `style.css` — оформление; `index.html` — страница.

Использование исходных фотографий для публичного размещения должно соответствовать правам владельца меню.

## Обновление оформления

Цвета и оформление перенесены из оригинального меню: фон #000, карточки #111, белый текст #fff, синие цены #007bff и кнопки #1e3a8a. Навигация сверху, фотокатегории с заголовками и карточки блюд с описаниями. Все фотографии локальные и в формате WebP. Сохранение заказов использует прежние ключи браузера.


## Меню Ферганы

Меню заменено на меню филиала Ферганы. Существующие заказы сохраняют прежние названия, цены и количество; новые позиции добавляются отдельно. Все фотографии блюд и категорий в формате WebP.
